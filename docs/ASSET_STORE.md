# Assets gratuits de l'Asset Store retenus

Sélection pour le rendu réaliste (et léger sur mobile). Pour chaque lien : bouton **Add to My Assets**
(connecté à ton compte Unity), puis dans Unity : *Window → Package Manager → My Assets* → **Download**
(pas besoin d'importer : je les importe et je les branche dans les générateurs).

Les packs de l'Asset Store sont sous la licence standard Unity (EULA de l'Asset Store) : utilisables
dans le jeu, pas redistribuables tels quels. Ils ne sont donc pas versionnés dans le dépôt
(dossier `Assets/ThirdParty/AssetStore/`, ignoré par git) ; voir aussi `docs/THIRD_PARTY.md`.
